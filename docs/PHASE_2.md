# Phase 2 — Language Profiles

## Included
- local user bootstrap (`local-user`)
- IndexedDB schema v2
- LanguageProfile storage
- add-language onboarding
- multiple learning languages
- active-language switching
- independent language data
- learning goals
- initial self-assessment
- language management in Settings

## Exit criteria
- one local user can add multiple languages
- profiles remain independent
- active language persists
- goals and starting skills persist
- deleting one profile does not affect others
- no account / multi-user UI
- no AI, SRS, speech, or Session Engine dependency
